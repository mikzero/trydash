Expose a dev service in one click, keep an eye on every tunnel and read their logs in one place. A single executable for Linux, macOS and Windows: nothing to install besides cloudflared.

Why

cloudflared tunnel --url http://localhost:3000 is great, but with two or three services running you end up with several terminals to watch, URLs to copy around and logs that are hard to read. trydash starts and manages quick tunnels for you.

Features

Many tunnels at once

Each with its status, URL and error count. To create one, just type the port: 3000 becomes http://127.0.0.1:3000.

Readable logs

Colored levels, filters, highlighted search, infinite scrolling and a “follow the tail” mode.

Email access

Limit a tunnel to specific addresses or whole domains (*@company.com). A list pasted from Outlook works too.

Live traffic

Requests in flight against the 200 limit, totals, errors, connections and a chart of the last 5 minutes.

Origin options

Host header, unverified TLS for self-signed certificates, HTTP/2 origin. A preview shows the equivalent cloudflared command.

Helpful warnings

It tells you when your origin isn’t responding, when you get close to the request limit and when a restart will change the URL.

Plus: a Hello World test without a local server, stopped tunnels you can still read, light and dark themes, a mobile layout and keyboard shortcuts. The interface is in Italian; error messages follow your browser, in English or Italian.

Download

  1. Install cloudflared

    It must be on your PATH. Follow Cloudflare’s guide; if it’s missing, trydash shows you the commands for your system.

  2. Download the executable

    SystemFile
    Linux x64trydash-1.0.0-linux-x64
    Linux ARM64trydash-1.0.0-linux-arm64
    macOS Apple Silicontrydash-1.0.0-darwin-arm64
    macOS Inteltrydash-1.0.0-darwin-x64
    Windows x64trydash-1.0.0-windows-x64.exe

    Check the file with SHA256SUMS: sha256sum -c SHA256SUMS --ignore-missing

  3. Run it

    chmod +x trydash-*-linux-x64     # Linux and macOS
./trydash-*-linux-x64

    Open the address it prints, usually http://127.0.0.1:8787, type your service’s port and press Crea (“Create”). On Windows, just run the .exe file.

    The binaries aren’t signed. On macOS, lift the Gatekeeper block with xattr -d com.apple.quarantine trydash-*; on Windows, if SmartScreen shows up, choose “More info” and then “Run anyway”.

Prefer to run from source? You need Bun ≥ 1.1: git clone https://github.com/mikzero/trydash.git && cd trydash && bun start.

Good to know about quick tunnels

  • the *.trycloudflare.com URL is random and changes on every start;
  • at most 200 concurrent requests per tunnel; beyond that the response is 429;
  • Server-Sent Events aren’t supported;
  • no uptime guarantee: for production you need a named Cloudflare Tunnel.

Security

  • the dashboard only listens on 127.0.0.1;
  • other pages open in your browser can’t control it;
  • no accounts, tokens or credentials: logs stay in memory;
  • a tunnel makes the service you expose public: protect it with email access.
